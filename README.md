# 超次元炒飯

中華鍋を振って米と具材を舞い上げ、タイミング評価と属性必殺技でハイスコアを狙う、Unity製3D料理アクションゲームです。

## 現在のプロトタイプ

- Spaceキーによる中華鍋の3D鍋振り
- 物理演算で動く米・卵・ネギ
- GOOD・GREAT・PERFECTの鍋振りタイミング評価
- 60秒のスコアアタックとA・B・Cランク
- 火・風・水・雷の属性切り替え
- 火属性必殺技「龍昇飯」
- 風属性必殺技「竜巻旋炒」
- スローモーション中のコマンド入力
- 炒魂ゲージと技ごとのクールタイム
- カメラ、パーティクル、効果音を組み合わせた必殺技演出

## 操作

| キー | 操作 |
|---|---|
| Space | 通常の鍋振り |
| P | 選択中の必殺技入力を開始 |
| ↑ / ← / ↓ / → | 火 / 風 / 水 / 雷へ属性変更 |
| A・D・W・Space | 必殺技のコマンド入力 |
| A連打 | 竜巻旋炒の風力上昇 |
| R | リザルトからリトライ |

詳しい仕様、企画意図、数値設定、開発中の調整記録は[ゲーム企画書](docs/GameDesignDocument.md)に記載しています。
